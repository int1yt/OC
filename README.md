# OC 创作台

一站式 OC 创作工具：帮助小红书创作者把散落的原创角色（OC）设定可视化、结构化、可分享，避免设定前后矛盾。Flutter 实现，本地优先（SQLite），移动端优先。

## 环境要求

- Flutter SDK 3.27+（Dart 3.6+）
- 构建工具链：`build_runner`（用于生成 drift 的 `.g.dart`）

## 首次构建

```bash
# 1. 安装依赖
flutter pub get

# 2. 生成 drift 数据库代码（必须，会生成 lib/src/data/database.g.dart）
dart run build_runner build --delete-conflicting-outputs

# 3. 运行
flutter run

# 打包发布 APK
flutter build apk --release   # 产物在 build/app/outputs/flutter-apk/app-release.apk
```

> 提示：若你用 Bevel 在 VS Code 中构建，Bevel 会补齐 android/ios 平台脚手架；只要保证先跑过 `flutter pub get` 和 `build_runner` 即可。

## 目录结构

```
lib/
  main.dart                       # 入口（加载持久化设置）
  src/
    app.dart                      # MaterialApp + 主题/背景 + 启动页 → 根路由
    core/                         # 常量、主题、工具、图片存取、页面路由
    data/                         # drift 表、数据库、仓库、导出/导入
    state/                        # Riverpod providers（作品/OC/关系/世界观/设置）
    features/
      splash/                     # 开机动画（手绘风螺线松树 + 3D 星）
      work/                       # 作品列表 + 切换到
      home/                       # 底部导航壳 + 设置页 + 功能导览
      character/                  # M1 人物库 + M2 人物详情（5 分区）
      relationship/               # M3 关系图谱
      world/                      # M4 世界观（层级树/地图/规则书/自检清单）
      share/                      # 分享卡片（3:4 PNG 导出）
```

## 功能详细说明

### 整体架构
- **多作品容器**：顶部为「当前作品」切换器，点作品名可切换/新建/删除作品；OC、关系、世界观、灵感均只在单个作品内有效。
- **本地优先 + 云端预留**：数据默认存本地 SQLite（drift），离线可用；设置页可导出/导入 zip 备份（`data.json + images/`），云端接口与格式已预留。
- **自动保存**：所有编辑即时写入本地，无需手动保存。
- **深/浅色主题**：跟随系统，可手动切换。
- **开机动画**：手绘风螺线松树（一深一浅随意盘旋）+ 树顶 3D 多面体立体星闪耀 + 树身周围亮光小星，带弹性入场；也可在设置里换成自定义图片。

### M1 人物库（首页）
- **卡片网格**：每个 OC 一张卡片，显示头像、姓名、MBTI 徽标、1~3 个标签、最近更新时间。
- **搜索 / 筛选 / 排序**：按姓名或标签搜索；按标签筛选；按最近更新 / 姓名 / 创建时间排序。
- **新建 / 重命名 / 复制 / 删除**：右上角「···」弹出操作（重命名、复制、删除整卡）。
- **标签系统**：作品级标签池，多选、新建、按颜色区分。
- **空状态**：无 OC 时提示创建第一个角色。

### M2 人物详情（OC 卡）
- **顶部人物头卡**（固定）：大头像（可上传，圆形）、姓名、年龄·性别·生日·星座元数据、编辑 / 分享卡片 / 更多按钮。
- **外貌特征**：按分区（体型 / 发色瞳色 / 服饰风格 / 特殊标志）图文混排，每条可加文字 + 多张图。
- **内在性格**：MBTI（16 型 + 一句话解读）、核心价值观（可拖排序）、优点 / 缺点、口头禅、扩展字段（键值对）。
- **背景故事**：原生家庭、人生转折点（与时间轴联动打星）、核心驱动力（立得住的关键）、目标 / 动机。
- **能力量化**：六维雷达图（战力/智力/魔力/敏捷/魅力/幸运），维度可改名 / 增删（3~8 维），每维 0~10 分 + 备注 + 能力总评。
- **人物时间轴**：纵向时间轴（最新/最旧可切换），每条事件可配图、拖排序；人生转折点自动打星标到时间轴。
- **分享卡片**：一键生成 3:4 竖版 PNG（头像/姓名/MBTI/雷达图/口头禅/标签，模块可勾选 + 排序 + 主题色），底部带水印，适配发小红书。

### M3 关系图谱
- **无限画布**：可平移（单指拖空白处）、缩放（双指/按钮）、适应视图。
- **节点**：圆形 OC 名称 + 底部实心端口，可拖动位置并持久化。
- **拖拽连线**：从节点底部圆点拖到另一节点建立关系。
- **关系编辑**：关系标签（预设 10 种 + 自定义）、关系强度（五档）、方向（单向/双向）、关系说明。
- **强度视觉编码**：撞色渐变双色 + 线型（亲密粉橙粗实线、友好绿黄实线、疏远灰虚线、敌对紫粉虚线、仇视深紫红粗虚线），并在连线上**直接显示关系标签文字**。
- **连线交互**：单击连线弹出气泡卡片（看详情 + 编辑 + 删除）；双击连线打开删除菜单。
- **自动排版**：力导向排版，亲密关系靠得更近、疏远/敌对离得更远。
- **图例**：显示强度颜色 + 线型。
- **背景切换**：纯白 / 虚线方格。
- **板块锁定**：锁定后仅平移/缩放画布，不响应节点/连线操作。

### M4 世界观
- **层级树**：多级地理结构（大陆→国家→城市→地标，层级名可自定义、层级数不限），可增删、编辑简介、移动层级。
- **地图标注**：上传手绘地图（不拉伸），在其上打点标注（名称 + 简介 + 地名标签随图缩放），图钉可拖动微调位置，支持多张地图切换、删除。
- **规则书**：按分区（魔法/科技、社会制度、货币度量衡、种族阵营、历史大事件、地理气候）录入条目（标题 + 正文），支持全文搜索。
- **合理性自检清单**：内置地理/经济/政治检查项，逐项标记「通过 / 存疑 / 不适用」+ 备注，可添加自定义项，一键导出检查报告。
- **板块锁定**：锁定后世界观的 4 个子 Tab 不能左右滑动切换，在地图里缩放/拖动不会跳到其他板块。

### 设置页
- **主题颜色**：6 个预设撞色搭配，全局换色。
- **应用背景图片**：可选自定义照片作为全屏背景，带透明度滑块。
- **开机动画图片**：可选自定义图替换默认开机动画。
- **关系强度颜色**：5 档强度各自可从 8 组撞色搭配中自行修改。
- **导出 / 导入**：全部数据 zip 备份（`data.json + images/`）与恢复。
- **功能导览**：右上角「?」进入 5 步图文操作指引。

## 验收自查（打包前逐条确认）

能完整创建一个 OC，填写全部字段并自动保存，刷新不丢数据；外貌图文混排；雷达图可改维度/增删维/调分值并实时重绘；人物时间轴与人生转折点联动打星；关系图谱可拖拽连线、标签/强度/方向、强度视觉区分；连接线双击/单击编辑删除；世界观层级树、地图打点标注、规则书搜索、自检清单导出；分享卡片导出 3:4 PNG。
